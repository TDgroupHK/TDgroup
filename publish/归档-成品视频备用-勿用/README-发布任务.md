## 发布规则（必须遵守）

1. **平台**：抖音、快手、小红书、微信视频号。各平台的标题与文案在 `发布文案-初创融资系列.md` 里按平台分好了，逐条复制，不要混用。
2. **节奏**：每天 1 条，按序号顺序发（01 → 05），发布时间 18:00–21:00；同一条当天各平台同步。
3. **封面**：上传时手动设置为对应的封面 PNG，不要用平台自动截帧。
4. **BGM**：视频是无声版，发布时在各平台 App/后台的**平台曲库**中选轻商务/纯音乐类 BGM 添加；禁止外挂第三方音乐文件（版权风险）。
5. **合规红线**（与官网 CLAUDE.md 同源，违反会被限流甚至封号）：
   - 抖音/快手/小红书/视频号的标题、文案、评论区**一律不出现**：网址、电话、微信号、二维码、「搜索XX」类引流话术。
   - 只有**微博**可以带链接（文案文件里微博版已含官网文章链接）。
   - 不修改文案中的数字与表述——所有数字都经过合规校验，不得自行加「保证」「稳赚」「第一」等词。
6. **账号简介**：如需更新，只写定位句（例：境外上市与跨境资本 · 初创融资系列更新中），不放任何联系方式。
