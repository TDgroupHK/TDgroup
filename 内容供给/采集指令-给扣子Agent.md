# 采集指令（给扣子空间的采集/生成 Agent）

任务：在抖音站内采集「创业公司老板」受众下已被验证的爆款内容，按《改写规范》重写为彤鼎版脚本后生成视频，交蚁小二分发。本文件定义**采什么、怎么判定已验证、采回来交什么**。

## 一、采集赛道与关键词库

按下面五个赛道轮询检索（抖音站内搜索+相关推荐链路均可）：

1. **股权类**：合伙人股权分配、股权五五开、股权代持、干股、股东协议、一票否决权、股权成熟、期权池、员工期权画饼
2. **公司法/新规类**：新公司法、注册资本实缴、五年实缴、认缴出资、一人公司、夫妻公司、连带责任、公司注销、吊销、法人代表风险
3. **财税类**：公转私、私户收款、金税四期、分红税、老板怎么拿钱、税务稽查、公私账混同
4. **融资类**：对赌协议、回购条款、天使投资、融资骗局、假投资人、服务费骗局、条款清单、估值
5. **资本市场类**：公司上市门槛、港股上市、纳斯达克、境外架构、红筹、家族信托

## 二、「已验证」的判定标准（满足其一才入库）

- 单条点赞 ≥ 5 万；或
- 同一选题在 ≥ 3 个不同账号出现 ≥ 1 万赞的版本（题材级验证，比单条爆款更可靠）；或
- 该选题下评论区出现大量「求下期/我就是这种情况/怎么办」类追问（需求信号）。

优先采**近 90 天**的爆款；常青题（代持/对赌/公转私）不受时间限制。

## 三、每条爆款采集后输出「采集卡」（只采骨架，不搬文案）

```
选题：
来源特征：账号类型（律师/财税/创业导师）+ 点赞量级 + 发布时间
前3秒钩子（大意转述，不逐字抄录）：
内容结构（分点列骨架，如：吓点→案例→3条对策→关注引导）：
评论区高频追问（3-5条）：
可接彤鼎的角度（初判）：
```

**注意：采集卡里不要逐字抄录对方文案，只记结构与大意**——后续重写必须脱离原文进行，这是版权与洗稿判定的安全线（见《改写规范》）。

## 四、采集频次与交付

- 每周一次全赛道扫描，每次产出 ≥ 10 张采集卡，存入本目录 `采集卡/` 子目录（按日期命名）。
- 与 `种子选题-已验证` 文件合并去重后，按热度排入生产队列。
- 生成视频前，逐条对照 `改写规范-版权与洗稿安全线.md` 与 `合规红线.md` 自检。
