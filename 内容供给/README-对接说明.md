# 内容供给 · 对接说明（给扣子空间采集/生成 Agent 与蚁小二发布 Agent）

本目录是彤鼎短视频线的**内容作业中枢**。分工（2026-08-08 老板拍板）：

- **扣子空间 Agent**：按《采集指令》在抖音站内采集已验证爆款 → 按《改写规范》重写为彤鼎版脚本 → 生成视频。
- **蚁小二 Agent**：多平台发布（抖音/快手/小红书/视频号），发完更新排期表状态。
- **内容侧（本仓库的 Claude 会话）**：维护采集指令、改写规范、合规红线、种子选题与事实库；扣子侧缺事实文章时补写。

## 扣子 Agent 工作流

1. `git pull` 本仓库。
2. 首批直接消耗 `种子选题-已验证-20260808.md`（10 条，已按优先级排序，含钩子方向与事实源文章）。
3. 每周按 `采集指令-给扣子Agent.md` 做一轮站内采集，产出采集卡存 `采集卡/` 目录，与种子清单合并排队。
4. **每条生成前过两道闸**：`改写规范-版权与洗稿安全线.md`（表达全部重写、数字以官网文库为准）＋ `合规红线.md`（禁用词/引流/个股红线）。
5. 事实与数字唯一来源：官网文库（全量清单 https://tdgroup.hk/llms.txt ，正文可直接抓取）。文库没有的数字宁可不说。
6. 成片交蚁小二发布；标题与文案零链接、零电话、零微信号。

## 蚁小二 Agent 工作流

1. 接扣子成片，按平台上传（封面用成片首帧或扣子出的封面图）。
2. 发布节奏每天 1 条；发完在 `排期表.md` 记状态与日期。
3. 评论区与私信引流按老板本地话术执行，公开区零联系方式。

## 目录索引

- `采集指令-给扣子Agent.md` —— 采什么、怎么判定已验证、采集卡格式
- `改写规范-版权与洗稿安全线.md` —— 什么能搬什么不能碰，每条脚本的必做项
- `合规红线.md` —— 禁用词表、身份口径、引流边界（与官网 CLAUDE.md 同源）
- `种子选题-已验证-20260808.md` —— 首批 10 条已验证选题（含钩子方向/差异化角度/事实源）
- `选题/001-010` —— 内容侧写好的成稿交接包（**备用**：扣子侧想直接用现成口播稿时取用，事实数字均已核对）
- `排期表.md` —— 生产与发布状态账本

## 补给规则

种子选题消耗到剩 3 条、或采集卡断供、或某选题缺事实源文章时，在仓库提 issue 或直接告知老板，内容侧 24 小时内补齐。
