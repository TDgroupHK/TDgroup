# 内容供给 · 对接说明（给视频制作与发布 Agent）

本目录是彤鼎「初创融资系列」短视频的**内容供给源**，由内容 Agent 持续产出并推送到本仓库。
分工：**本目录只管内容（选题/口播稿/字幕要点/分平台文案）；视频制作与多平台发布由你按你们与老板约定的方式执行（蚁小二分发）。**

## 使用流程

1. `git pull` 本仓库，进入 `内容供给/选题/`。
2. 打开 `排期表.md`，找状态为「待制作」的最小编号选题。
3. 按该选题 Markdown 文件里的字段制作视频：
   - `口播稿` = 配音/口播文本（约 55 秒，可直接 TTS 或真人录）
   - `字幕要点卡` = 分镜/贴片字幕
   - `视频标题` + 各平台文案 = 发布时逐平台复制，**不要混用**
4. 发布平台：抖音、快手、小红书、微信视频号（微博如发，用文件里的微博段，只有微博可带链接）。
5. 发完在 `排期表.md` 把该条状态改为「已发布」并附日期，push 回本仓库（或回报老板）。

## 硬性合规（每条都要过，违反会限流封号）

- 标题、文案、评论区**一律不出现**：网址、电话、微信号、二维码、「搜索XX」引流话术（仅微博段例外，文件里已写好）。
- 不得改动稿件中的数字与结论；不得自行添加「保证」「稳赚」「第一」「顶级」「最强」等词。
- 不提任何股票代码、具体上市公司的股价涨跌；不承诺融资/收益结果。
- BGM 用平台曲库，不外挂第三方音乐文件。
- 完整词表见 `合规红线.md`。

## 供给节奏

- 首批 001–010 已就绪（10 条完整交接包）。
- 排期表另列 011–030 选题队列，内容 Agent 按消耗速度持续补稿：**排期表里「待写稿」少于 5 条时，在仓库提 issue 或告知老板，内容侧会加产。**
